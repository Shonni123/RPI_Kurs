### 1. Цели и задачи проекта

#### 1.1. Цель проекта
Создание интуитивно понятного, высокопроизводительного и отзывчивого веб-интерфейса сервиса мониторинга и отслеживания авиарейсов в реальном времени.

#### 1.2. Основные задачи
1. Реализовать адаптивный пользовательский интерфейс по макетам (Mobile, Tablet, Desktop) с сохранением фирменной стилистики и микроанимаций.
2. Спроектировать компонентную архитектуру React-приложения с разделением ответственности (`components`, `pages`, `hooks`, `services`, `types`).
3. Настроить клиентский роутинг на базе `react-router-dom` с поддержкой минимум 6 страниц, динамических маршрутов и страницы ошибки 404.
4. Обеспечить корректную обработку всех состояний асинхронных данных: `loading` (скелетоны/спиннеры), `error` (обработка сбоев), `empty state` (отсутствие результатов поиска/избранного).
5. Разработать REST API на Django + Django REST Framework для управления рейсами, аэропортами, статусами и избранным.
6. Упаковать проект в Docker (контейнеры для фронтенда и бэкенда с `docker-compose`).
7. Провести замеры производительности (FCP, LCP, Bundle Size, Re-renders) и UX-исследование по шкале SUS.

### 2. Целевая аудитория (ЦА)

1. **Авиапассажиры и путешественники:** люди, которым необходимо быстро узнать статус своего рейса, терминал вылета, гейт и возможные задержки.
2. **Встречающие и провожающие:** пользователи, отслеживающие точное время посадки и статус борта в режиме реального времени.
3. **Часто летающие пассажиры (бизнес-сегмент):** пользователи, ценящие скорость работы, отсутствие рекламы, возможность быстро сохранять рейсы в избранное и подписываться на обновления.

### 3. Пользовательские сценарии (User Stories)

| ID | Роль | Действие (User Story) | Критерий приемки (Acceptance Criteria) |
|---|---|---|---|
| **US-01** | Гость / Пассажир | Как пользователь, я хочу видеть презентационный лендинг с преимуществами и статистикой сервиса | Отображаются Hero-баннер, карточки преимуществ, виджет текущего рейса, статистика и FAQ. |
| **US-02** | Пассажир | Как пассажир, я хочу искать рейсы по номеру рейса, городу вылета и прилета | Форма поиска с фильтрами в реальном времени, отображение состояний загрузки и пустого результата. |
| **US-03** | Пассажир | Как пользователь, я хочу открыть карточку конкретного рейса (`/flights/:id`) | Отображение подробностей: модель самолета, терминал, гейт, статус (В полете / Задержан / Прибыл), интерактивный прогресс маршрута. |
| **US-04** | Встречающий | Как встречающий, я хочу посмотреть табло конкретного аэропорта (`/airports/:code`) | Список вылетов и прилетов выбранного аэропорта с возможностью фильтрации по статусу. |
| **US-05** | Пользователь | Как пользователь, я хочу добавлять рейсы в «Избранное» | Сохранение рейсов в локальное хранилище / БД, просмотр сохраненных рейсов на отдельной странице `/favorites`. |
| **US-06** | Пользователь | Как пользователь, я хочу подписаться на email-рассылку | Валидация email, обратная связь об успешной подписке, отправка на бэкенд. |
| **US-07** | Пользователь | Как пользователь, я хочу при переходе по несуществующему адресу видеть понятную страницу 404 | Стилизованная страница 404 в авиационной стилистике с кнопкой быстрого возврата на главную. |

### 4. Структура страниц (Роутинг)

1. `/` — Главная страница (Лендинг по дизайну из Figma)
2. `/flights` — Онлайн-табло и поиск рейсов с фильтрацией
3. `/flights/:id` — Детальная страница конкретного авиарейса (динамический роут)
4. `/airports` — Каталог аэропортов и направлений
5. `/favorites` — Избранные и отслеживаемые рейсы
6. `/about` — О проекте, технологии и архитектура сервиса
7. `*` — Страница 404 (Not Found)

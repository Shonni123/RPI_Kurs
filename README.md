# Разработка веб-интерфейса для информационного сервиса об авиарейсах

Веб-приложение для мониторинга и отслеживания авиарейсов в режиме реального времени. Проект разработан в рамках курсовой работы по дисциплине «Разработка программных интерфейсов» (РПИ).

## Стек технологий
* **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS, React Router v7, Lucide Icons.
* **Backend:** Python 3, Django, Django REST Framework, SQLite.
* **Анализ производительности:** Rollup Visualizer, Google Lighthouse.

## Страницы приложения (Роутинг `react-router-dom`)
1. `/` — **Главная страница (Лендинг):** Полная адаптивная копия макета из Figma (Hero с виджетом рейса SU 1702, карусель «Почему мы?», блок «Ваш полёт под контролем», статистика «FLIGHTS», форма подписки на рассылку, интерактивный аккордеон FAQ).
2. `/flights` — **Онлайн-табло и поиск рейсов:** Живой поиск по номеру рейса, городам и аэропортам, фильтры по статусам («В полёте», «Ожидает взлёта», «Задержан», «Прибыл») и авиакомпаниям, сортировка, обработка состояний загрузки/ошибки/пустого списка.
3. `/flights/:id` — **Детальная карточка рейса (Динамический маршрут):** Телеметрия борта (высота, скорость), прогресс перелёта, терминалы и гейты вылета/прилёта, прогноз погоды.
4. `/airports` — **Каталог аэропортов:** Справочник узловых хабов (SVO, DME, VKO, LED, DXB, IST) с количеством вылетов и прилётов.
5. `/favorites` — **Избранные рейсы:** Персональный трекер рейсов с сохранением в `localStorage`.
6. `/about` — **О сервисе и архитектуре:** Информация о целях, стеке и методиках оптимизации.
7. `*` — **Страница 404:** Стилизованная страница ошибки маршрутизации с кнопками возврата.

## Запуск проекта

### Запуск фронтенда:
```bash
cd frontend
npm run dev
```
Приложение откроется в браузере по адресу: [http://localhost:3000](http://localhost:3000)

### Сборка и генерация отчёта по размеру бандла:
```bash
cd frontend
npm run build
```
Отчёт сформируется в файле `frontend/stats.html` — его можно открыть в любом браузере для демонстрации преподавателю.
